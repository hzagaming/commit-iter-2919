# commit-iter-2919

每次提交把版本号 +1，从 **iter 2919** 开始，满 10000 进一位。

## 版本号规则

| 迭代号 | 版本号 |
| --- | --- |
| 2919 | `v0.0.2919` |
| 9999 | `v0.0.9999` |
| 10000 | `v0.1.0000` |
| 10001 | `v0.1.0001` |
| 100000000 | `v1.0.0000` |

修订号满 10000 进位到次版本号，次版本号满 10000 进位到主版本号。主次都为 0 时只显示 `0.0.N`，一旦进位则修订号补足 4 位。

## 用法

```bash
python3 iter_commit.py --once        # 提交一次
python3 iter_commit.py --loop 30     # 每 30 秒提交一次并推送
python3 -m unittest discover -s tests
```

每轮改动 `VERSION` 和 `CHANGELOG.md` 并提交，提交信息形如 `release: v0.0.2920 (iter 2920)`。
